# Reasoning & External Memory

Giving a network somewhere to write and something to reason over: differentiable memory and relational reasoning modules.

## Papers

1. [16 - Neural Turing Machines](/papers/16-neural-turing-machines.md) - Alex Graves, Greg Wayne et al. (2014). A neural network coupled to an external memory matrix that it learns to read from and write to with differentiable operations.
2. [17 - A Simple Neural Network Module for Relational Reasoning](/papers/17-simple-neural-network-module-for-relational-reasoning.md) - Adam Santoro, David Raposo et al. (2017). The Relation Network: a small module that reasons explicitly over all pairs of objects, giving strong results on CLEVR-style visual question answering and showing how little machinery relational inference needs..
3. [18 - Relational Recurrent Neural Networks](/papers/18-relational-recurrent-neural-networks.md) - Adam Santoro, Ryan Faulkner et al. (2018). Puts a relation-network memory inside a recurrent network so that separate facts in memory can interact with each other - relational reasoning carried across time rather than over a single snapshot..
