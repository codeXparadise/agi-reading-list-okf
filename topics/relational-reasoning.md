# Relational Reasoning

Reasoning explicitly over the relations between pairs or groups of entities rather than over their raw features.

## Why it matters in this list

Relational modules are a compact demonstration that some problems need structure in the architecture, not just more parameters.

## Papers

- [17 - A Simple Neural Network Module for Relational Reasoning](/papers/17-simple-neural-network-module-for-relational-reasoning.md) (2017) - The Relation Network: a small module that reasons explicitly over all pairs of objects, giving strong results on CLEVR-style visual question answering and showing how little machinery relational inference needs..
- [18 - Relational Recurrent Neural Networks](/papers/18-relational-recurrent-neural-networks.md) (2018) - Puts a relation-network memory inside a recurrent network so that separate facts in memory can interact with each other - relational reasoning carried across time rather than over a single snapshot..
- [30 - Neural Message Passing for Quantum Chemistry](/papers/30-neural-message-passing-for-quantum-chemistry.md) (2017) - Shows that a wide family of graph neural networks is really one message-passing algorithm, and sets a strong benchmark on molecular property prediction..
